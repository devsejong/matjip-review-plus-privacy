매장을 비교할 때 읽는 정보

네이버 지도나 카카오맵에서 음식점을 선택하면, 화면에 공개된 상호·주소·전화번호와 매장을 구분하는 번호, 페이지 주소를 읽습니다. 같은 음식점인지 확인하고 다른 서비스의 평점과 리뷰 수를 보여주기 위해서입니다.

비교 대상은 네이버 지도, 카카오맵, 구글맵, 다이닝코드, 캐치테이블입니다. 이 중 현재 보고 있는 지도를 제외한 서비스에 매장 이름을 검색어로 전달합니다. 구글맵에는 같은 이름의 다른 매장과 구분할 수 있도록 공개된 매장 주소도 함께 전달합니다.

이용자의 계정 프로필, 로그인 정보, 개인 저장 목록은 읽지 않습니다. 현재 위치 좌표를 읽거나 전송하지 않으며, 일반 방문기록을 수집하거나 이용 성향을 분석하지 않습니다.

리뷰를 열었을 때

‘리뷰 보기’를 누르면 해당 매장의 공개 리뷰 본문과 작성자 닉네임, 작성일, 평점을 읽습니다. 처음에는 최대 3개를 보여주고, ‘더보기’를 누르면 추가로 읽어옵니다. 본문은 처음 240자부터 보여주며, 펼쳤을 때 리뷰당 최대 6,000자까지 확인할 수 있습니다.

읽어온 리뷰는 패널을 열어둔 동안만 임시로 보관합니다. 다른 매장으로 바꾸거나 패널을 닫으면 지워지며, 별도 서버나 영구 저장소에 저장하지 않습니다. 다음 더보기에서 보여줄 리뷰도 잠시 보관해 재사용할 수 있습니다.

같은 리뷰를 중복해서 보여주지 않기 위해 본문·닉네임·작성일을 비교하거나 구글의 공개 리뷰 번호를 사용합니다. 이 중복 확인용 정보는 확장 내부에서만 사용합니다. 로그인이나 접근 제한을 우회하지 않으며, 패널에서 읽을 수 없는 리뷰는 원문으로 안내합니다.

브라우저에 남는 정보

자동 비교를 켜거나 끈 설정은 다음에 사용할 때도 유지됩니다. 선택한 매장과 비교 결과, 조회용 탭·창을 구분하는 정보는 브라우저 세션에 임시로 저장합니다. 탭별 상태는 해당 탭을 닫으면 삭제하고, 비교 결과 캐시는 10분이 지나면 정리합니다. 세션이 끝나면 이 임시 정보도 사라집니다.

확장 프로그램을 삭제하면 확장이 저장한 설정과 데이터가 삭제됩니다. 다만 조회 과정에서 브라우저에 남은 방문기록이나 각 서비스가 보관하는 정보는 별도로 관리해야 합니다.

다른 서비스에 접속하는 방식

매장을 비교하는 동안 현재 화면을 바꾸지 않는 임시 탭을 엽니다. ‘전체 다시 찾기’에서 캐치테이블 주소를 확인하거나 구글맵의 추가 리뷰를 가져올 때는 보조 창이 잠시 열릴 수 있습니다. 조회가 끝나면 닫지만, 이용자가 직접 선택한 탭이나 창은 자동으로 닫지 않습니다.

이 접속은 브라우저에서 해당 사이트를 여는 방식으로 이루어집니다. 각 서비스는 IP 주소, 브라우저 정보, 그 서비스에 저장된 쿠키를 받을 수 있으며, 이때는 해당 서비스의 개인정보처리방침이 적용됩니다. 맛집리뷰더하기가 인증 쿠키를 읽거나 운영자에게 전송하는 것은 아닙니다. 원문 링크를 누른 뒤의 이용에도 해당 서비스의 방침이 적용됩니다.
