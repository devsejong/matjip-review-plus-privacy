맛집리뷰더하기 개인정보처리방침

맛집리뷰더하기 0.7.2 / 2026-09-29

확장은 네이버 지도 또는 카카오맵에서 현재 선택한 음식점의 공개 이름·주소·전화번호·장소 ID를 읽습니다. 해당 이름(구글맵은 공개 매장 주소도 포함)으로 원본 지도를 제외한 네이버 지도 또는 카카오맵, 구글맵, 다이닝코드, 캐치테이블의 검색 페이지를 열고 공개 매장 정보를 비교합니다. 인증정보·계정 프로필·개인 저장 폴더는 수집하지 않습니다. 네이버 검색 결과에 표시된 사용자의 현재 위치 좌표도 읽거나 전송하지 않습니다.

음식점 검색어는 해당 서비스에 전달되며 그 서비스의 정책이 적용됩니다. 맛집리뷰더하기 자체 운영 서버, 분석 도구, 광고 SDK, 외부 텔레메트리는 없습니다.

자동 조회 설정은 이 브라우저의 chrome.storage.local에 저장됩니다. 탭별 매장 정보·조회 결과·임시 탭·창 식별자는 chrome.storage.session에 보관됩니다. 탭 상태는 닫힐 때 삭제되고 캐시는 10분 후 정리됩니다. 브라우저 세션이 끝나면 세션 데이터는 소멸합니다. 브라우저 자체 방문기록은 서비스 페이지 방문에 따라 남을 수 있으며 확장에서 별도로 수집하거나 삭제하지 않습니다.

사용자는 자동 조회를 끄거나 확장 프로그램을 비활성화/삭제할 수 있습니다. 문의는 아래 배포자 이메일로 보내실 수 있습니다.

음식점 상세페이지 또는 카카오맵의 주소·연락처 정보창 선택 시 자동 조회를 실행하며 인라인 요약 영역에서 끌 수 있습니다. 기본 조회는 네 서비스 모두 비활성 탭을 사용합니다. 상세 패널에서 다시 찾기를 직접 실행할 때 캐치테이블 주소 확인용 별도 비포커스 창이 잠시 열립니다. 사용자가 해당 조회 탭·창을 직접 선택하면 자동 제어를 중단하고 열린 상태로 남깁니다.

사용자가 상세 패널의 리뷰 보기를 누른 경우에만 해당 매장의 공개 리뷰 본문 일부(처음 3개 및 더보기로 추가한 리뷰, 각 최대 6,000자, 처음에는 240자를 표시), 공개 작성자 닉네임, 표시된 날짜와 평점을 읽습니다. 본문은 패널 메모리에서만 사용하며 저장소·자체 서버에 보관하거나 전송하지 않습니다. 다른 매장 선택 또는 패널 종료 시 해제됩니다. 캐치테이블의 로그인 제한은 우회하지 않고 원문을 안내합니다. 원문 링크를 누르면 사용자가 직접 해당 서비스를 이용합니다.

리뷰 더보기를 누르면 이미 표시한 리뷰의 식별용 본문·닉네임·날짜 조합 또는 구글 공개 리뷰 ID를 확장 내부 작업에 전달해 중복을 제거합니다. 이 값은 외부 서비스에 전송하지 않습니다. 원문 첫 목록에 함께 표시된 리뷰는 패널 메모리에 임시로 보관해 다음 더보기에서 재사용합니다.

구글맵 리뷰 더보기에서 새 목록을 가져올 때는 비포커스 보조 창을 잠시 사용합니다. 미리 읽은 리뷰를 펼칠 때는 창을 열지 않습니다. 조회가 끝나면 자동으로 닫으며, 사용자가 직접 선택한 창은 닫지 않습니다.

처리 목적과 사용 제한

읽은 데이터는 같은 매장 확인, 서비스별 평점·리뷰 표시, 오류 복구에만 사용합니다. 데이터를 판매하거나 광고 타기팅, 신용 평가, 대출 목적으로 이용하지 않습니다. 일반 방문기록을 수집하거나 사용자 행동 프로필을 만들지 않습니다. 지원 지도에서 선택한 매장 URL·장소 ID와 조회에 필요한 서비스 URL을 처리합니다.

외부 서비스 방문

검색과 원문 열기는 해당 서비스에 대한 일반 브라우저 요청입니다. 이 과정에서 서비스가 IP 주소, 브라우저 정보, 해당 서비스의 기존 쿠키를 받을 수 있으며 서비스 자체 정책이 적용됩니다. 확장은 인증 쿠키를 읽거나 자체 서버로 전송하지 않습니다. 확장 삭제 시 확장 저장소는 삭제되지만 외부 서비스가 보관한 자료나 브라우저 방문기록은 별도로 관리됩니다.
